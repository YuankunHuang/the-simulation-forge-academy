# 变更日志

## v0.2 — Focus, Game Loop, Evidence Polish（2026-07-03）

本次迭代不加新功能范围，专注把应用从「功能面板」打磨成「知道下一步做什么的驾驶舱」。主线锚定 Unity Native Boundary Lab 的 R0 → M0 → M1 → M2 → M3。

### 炉火大厅（焦点重构）

- 视觉层级重排：导师问候 → **今日任务英雄卡（页面主角）** → 节奏选择 → 进度条 → 次级入口。
- 英雄卡展示：任务编号/标题、区域、预计时间、一句「为什么重要」、必交证据数、奖励预览，主按钮「进入工坊」、次按钮「查看地图」。
- 导师横幅压缩为一句主话 + 一行小字；职业称号与五种货币收敛为单行进度条；动量之火并入进度条（悬停可见详情）。
- 快捷入口从大卡降级为小按钮行。

### 深度冲刺（状态机修复）

- 明确三态：**待命（idle）→ 进行中（active）→ 已结束（ended）**。
- 选择「深度冲刺」模式不再自动开始冲刺——必须点击「开始冲刺」显式开启（`startSprint` 动作）。
- 进行中横幅：「深度冲刺进行中：已完成 X 个任务」+「继续下一关」「结束冲刺」按钮。
- 结束后生成 Session Recap 写入篝火日志；**空冲刺（0 任务）不产生回顾**，避免日志噪音。
- 非活动状态不再显示「冲刺进行中」。

### 工坊 / 任务详情（结构硬化）

- 段落按规格重排：叙事钩子 → 目标 → 为什么重要 → DoD → **证据要求概览（新增）** → AI Prompt → 常见陷阱 → 当前禁止事项 → 面试讲法 → 提交证据 → 完成任务。
- 「当前禁止事项」清单更新为七条（新增 Unreal mirror；课程条目改为「除非解决当前卡点」）。
- 资源建议并入 AI Prompt 卡片，减少页面卡片数。

### 奖励仪式

- 新增「N 张知识卡进入复习卡组」区块（列出卡片问题）。
- 按钮对齐规格：**继续下一关**（主）、**回到炉火大厅**、**查看证据宝库**（有神器时）；「结束冲刺并生成回顾」降级为底部文字链。

### 证据宝库

- 锁定神器差异化：显示真实名称（弱化样式）、稀有度、来源任务、**每件专属的悬念 teaser**；不再重复「未铸造的神器」，展示内容保持隐藏。
- 解锁神器详情新增「铸造它的证据」区块（回显当时提交的证据）。
- 七类展示内容全部配复制按钮（LinkedIn/博客复制完整 AI 起草 Prompt）。
- M0–M3 四件神器文案深度强化（proves/careerValue/五类建议全部具体化）。

### 复习卡组

- 空状态从被动安慰改为主动引导：解释卡片来源、指出下一批卡藏在哪个任务（如「完成 M2 后，extern "C"、DllImport、Native Plugin Loading 会进入卡组」）、附直达按钮。
- 当推荐任务自带知识卡时，提供一张**可选预习卡**（学前检索）；不伪造到期卡。

### 征程地图

- 当前区域：琥珀描边 + 光晕 +「当前区域」徽章；时间线节点同步高亮。
- 当前任务 chip：实心琥珀 +「当前」标签，一眼可见。
- 任务链以箭头连接（M0 → M1 → M2 → M3 → Boss），完成节点转为安静的苔绿。
- 迷雾规则不变。

### 引擎与存档

- `reviewEngine` 新增 `cardsUnlockedBy(questId)` 与 `getUpcomingCardInfo(completedIds)`（+4 个单元测试，总计 54 个）。
- `playerStore`：`setEnergyMode` 与冲刺解耦；新增 `startSprint`；`endSprint` 跳过空冲刺；`CeremonyPayload` 新增 `reviewCardIds`。
- `Artifact` 类型新增 `teaser` 字段。
- 存档结构向后兼容（新字段均有兜底），导出/导入不受影响。

### 已知限制

- 冲刺「已结束」提示为会话内状态，刷新后不再显示（回顾永久保存在篝火日志）。
- 旧存档中进行中的冲刺会保留为 active 状态（行为正确，无需迁移）。
