# 变更日志

## v0.5 — Boss 答辩体验：逐题引导 + AI 演练（2026-07-04）

Boss 之门从「一排普通表单」升级为面试式的逐题答辩体验。适用于全部 6 座 Boss，无需修改任何任务内容。

### Boss 答辩表单（新组件 `BossDefenseForm`）

- 每道必答题渲染为独立问题卡：编号圆标（作答合格后变绿色对勾）、题目、作答区、字数计。
- **每题配一枚「演练 Prompt」按钮**：复制后交给 AI，AI 扮演严格面试官只围绕这一题演练——先听完整陈述、再追问 2-3 个、指出遗漏机制、最后给 60-90 秒改进示范。
- 顶部答辩进度条：已答 X / N 实时更新。
- 可选题（如面试防线草稿）以虚线卡呈现，不阻塞开门。
- 提交按钮文案改为「提交答辩，开启之门」，未完成时显示「还差 N 题必答」。

### 答辩文本一键取用

- 引擎新增 `assembleDefenseText(quest, fields)` 纯函数：按题目顺序拼装非空作答，`playerStore` 写篝火日志与 UI 复制共用（消除此前 store 内联逻辑）。
- Boss 完成回执改为「答辩存档」，附**「复制完整答辩」**按钮。
- 篝火日志的 Boss 答辩条目同样新增复制按钮——面试前直接取用。

### 引擎与测试

- `evidenceEngine` 新增 `defenseDrillPrompt` / `assembleDefenseText`（+3 个用例：Prompt 上下文完整性、拼装顺序与空题跳过、全空不写日志）。测试总数 75 → **78**，全部通过。

## v0.4 — Act I 全线深化：基准平原到移动之门（2026-07-04）

延续 v0.3 的深化方向，把 Act I 其余全部内容（M4–M13 与 5 座剩余 Boss 之门）提升到与基础弧线同等的工坊深度。解锁节奏不变：这些内容仍按迷雾与门控逐步开放，只是玩家到达时不再遇到「薄任务」。

### 任务深度（M4–M13）

- 十个里程碑任务全部补齐五个深度字段：概念链、产物清单、分步执行计划、调试笔记、公开展示种子。
- 内容技术具体化到可执行级别，例如：
  - M4：导出 `NblGetAgentSize()` 运行时对表、`static_assert(offsetof…)` 双侧锁定布局；
  - M5：`std::span` 包借用内存、GCHandle pin 陷阱、count 单位约定写死在头文件注释；
  - M7：`ProfilerRecorder` 采样 GC alloc、vsync 钳制帧时的处理、分位数不用平均值；
  - M8：Burst Inspector 确认向量化生效、并行度对等的公平性声明；
  - M12：`llvm-readelf` 验证目标架构、解压 APK 确认 `.so` 打包、IL2CPP 构建期符号静态检查。

### Boss 之门补完（五枚新之印）

- 每座 Boss 之门现在都铸成专属神器（含完整八段展示内容：证明/职业价值/LinkedIn/博客/作品集/简历/面试）：
  - 平原试炼之印（Legendary）——Act I 公开 demo 切片的发布时刻
  - Blittable 契约之印（Epic）、失败协议之印（Epic）
  - 港口放行印（Legendary）、ARM64 通行印（Legendary，Act I 落款）
- 全部 6 座 Boss 均补齐深度字段与答辩步骤引导；答辩全文继续自动存入篝火日志。
- 神器总数 18 → **23**。

### 米拉台词补完

- `quest_focus` 台词覆盖 Act I 全部 21 个主线/Boss 任务（新增 M6–M13 与 5 座 Boss），每到一关，大厅主句都是该关专属引导。

### 复习卡扩充

- 新增 5 张卡：AoS/SoA 判断标准（M9）、asmdef 的作用与 Samples~ 机制（M11×2）、IL2CPP vs Mono 与 ABI 目录（M12×2）。卡组总数 26 → **31**。

### 测试

- 内容完整性守卫升级：深度字段与 quest_focus 台词检查从「基础弧线 6 关」扩展到 **Act I 全部主线与 Boss**；新增「每座 Boss 必产一枚之印」不变量。测试总数 74 → **75**，全部通过。

### 未变更

## v0.3 — Foundational Arc v1：内容深化 + 营地支线 + 证据展示系统（2026-07-03）

本次迭代聚焦基础弧线（R0 → M0 → M1 → M2 → M3 → 初次信号之门）的内容深度、任务感知导师、Act 0 生产经验营地支线，以及证据展示系统。不扩张 M4+ 远期范围，未来区域保持迷雾。

### 世界结构：生产经验营地（Act 0 支线）

- 新增支线区域「生产经验营地 / Production Basecamp」：点燃炉火（R0）后开放，**永不阻塞主线、永不劫持推荐**。
- 6 个可选任务，把 5 年 Unity 移动生产经验变成显性证据：
  - B1 生产装备盘点（产出「生产装备图谱」神器）
  - B2 Unity 运行时心智模型
  - B3 移动生产摩擦提取
  - B4 C# 热路径审计
  - B5 玩法与仿真分离论（为 Act II 打思想地基）
  - B6 职业故事提取器（产出「职业叙事卷轴」神器）
- 引擎支持 `Region.side` 支线区域：独立解锁，不占用主线迷雾预览位；地图上标注「可选支线」，任务间不画顺序箭头。

### 任务内容深化（R0–M3 + Boss）

- `Quest` 类型新增五个深度字段：`conceptMap`（概念链）、`filesToCreate`（产物清单）、`steps`（分步执行计划）、`debuggingNotes`（调试笔记）、`publicShowcaseSeed`（公开展示种子）。基础弧线六个任务全部填充。
- R0 重铸为「确认转职路线」仪式：一句话意图 + 主线项目确认 + 可选反思，产出**炉火誓约**神器，解锁 Evidence-based Progression / Career North Star 技能（附 2 技能点即时点亮）。
- M0 挂接 Project Scoping / Repository Scaffold / Technical Thesis 技能；M1 补挂 extern "C"。
- 初次信号之门从三问升级为**五问答辩**（新增「为什么不暴露 C++ class」「与确定性仿真的关系」），要求集齐五件神器，铸成新神器**桥村之印**（Epic），答辩全文自动存入篝火日志作为面试防线。
- M1/M2/M3 的常见陷阱、禁止事项按规格补全（如「M1 稳定前不做 P/Invoke」）。

### 任务感知导师

- 米拉新增 `quest_focus` 台词：R0/M0/M1/M2/M3/Boss/M4/M5 各有专属主句（如 M0：「今天不是写复杂代码，而是给整个边界实验室打地基」）。

- 英雄卡新增当前节奏指示（冲刺中 / 低能量节奏）。

### 工坊十六段结构 + 折叠面板

## v0.2 — Focus, Game Loop, Evidence Polish（2026-07-03）

本次迭代不加新功能范围，专注把应用从「功能面板」打磨成「知道下一步做什么的驾驶舱」。主线锚定 Unity Native Boundary Lab 的 R0 → M0 → M1 → M2 → M3。

### 炉火大厅（焦点重构）

- 视觉层级重排：导师问候 → **今日任务英雄卡（页面主角）** → 节奏选择 → 进度条 → 次级入口。
- 英雄卡展示：任务编号/标题、区域、预计时间、一句「为什么重要」、必交证据数、奖励预览，主按钮「进入工坊」、次按钮「查看地图」。
- 导师横幅压缩为一句主话 + 一行小字；职业称号与五种货币收敛为单行进度条；动量之火并入进度条（悬停可见详情）。
- 快捷入口从大卡降级为小按钮行。

### 深度冲刺（状态机修复）

- 明确三态：**待命（idle）→ 进行中（active）→ 已结束（ended）**。
- 选择「深度冲刺」模式不再自动开始冲刺——必须点击「开始冲刺」显式开启（`startSprint` 动作）。
- 进行中横幅：「深度冲刺进行中：已完成 X 个任务」+「继续下一关」「结束冲刺」按钮。
- 结束后生成 Session Recap 写入篝火日志；**空冲刺（0 任务）不产生回顾**，避免日志噪音。
- 非活动状态不再显示「冲刺进行中」。

### 工坊 / 任务详情（结构硬化）

- 段落按规格重排：叙事钩子 → 目标 → 为什么重要 → DoD → **证据要求概览（新增）** → AI Prompt → 常见陷阱 → 当前禁止事项 → 面试讲法 → 提交证据 → 完成任务。
- 「当前禁止事项」清单更新为七条（新增 Unreal mirror；课程条目改为「除非解决当前卡点」）。
- 资源建议并入 AI Prompt 卡片，减少页面卡片数。

### 奖励仪式

- 新增「N 张知识卡进入复习卡组」区块（列出卡片问题）。
- 按钮对齐规格：**继续下一关**（主）、**回到炉火大厅**、**查看证据宝库**（有神器时）；「结束冲刺并生成回顾」降级为底部文字链。

### 证据宝库

- 锁定神器差异化：显示真实名称（弱化样式）、稀有度、来源任务、**每件专属的悬念 teaser**；不再重复「未铸造的神器」，展示内容保持隐藏。
- 解锁神器详情新增「铸造它的证据」区块（回显当时提交的证据）。
- 七类展示内容全部配复制按钮（LinkedIn/博客复制完整 AI 起草 Prompt）。
- M0–M3 四件神器文案深度强化（proves/careerValue/五类建议全部具体化）。

### 复习卡组

- 空状态从被动安慰改为主动引导：解释卡片来源、指出下一批卡藏在哪个任务（如「完成 M2 后，extern "C"、DllImport、Native Plugin Loading 会进入卡组」）、附直达按钮。
- 当推荐任务自带知识卡时，提供一张**可选预习卡**（学前检索）；不伪造到期卡。

### 征程地图

- 当前区域：琥珀描边 + 光晕 +「当前区域」徽章；时间线节点同步高亮。
- 当前任务 chip：实心琥珀 +「当前」标签，一眼可见。
- 任务链以箭头连接（M0 → M1 → M2 → M3 → Boss），完成节点转为安静的苔绿。
- 迷雾规则不变。

### 引擎与存档

- `reviewEngine` 新增 `cardsUnlockedBy(questId)` 与 `getUpcomingCardInfo(completedIds)`（+4 个单元测试，总计 54 个）。
- `playerStore`：`setEnergyMode` 与冲刺解耦；新增 `startSprint`；`endSprint` 跳过空冲刺；`CeremonyPayload` 新增 `reviewCardIds`。

### 已知限制
